# Products counter
This project was inspired by the passenger counter app, a part of the [Scrimba](https://scrimba.com?via=u418292a) full-stack tutorial.
## Purpose
To count products purchased (or anything you'd like to customize the app to count), giving you the previous entries and the total count.
